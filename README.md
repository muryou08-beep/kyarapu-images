# 最強を引いたら最初の相棒もついてきた — 場面画像

GitHub Pages で配信する物語用の画像です。

- `index.html`: 画像一覧（29枚）
- `s1.png` 〜 `s6.png`: 導入の場面画像
- `s7.png`・`s8.png`: 映画館の場面画像
- `e1.png` 〜 `e21.png`: 日常イベントの場面画像
- `assets.json`: 画像名・ファイル名・寸法・SHA-256 の対応表

物語で参照しているファイル名と階層を維持してください。
このフォルダーには、生成用プロンプト、会話ログ、ローカル環境の情報を含めていません。
